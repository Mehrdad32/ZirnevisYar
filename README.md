# ZirnevisYar — زیرنویس‌یار

An open-source Persian subtitle conversion utility by Mehrdad32.

## Web application (new)

A responsive, browser-only version is in [web/](web/README.md).
Target website: https://zirnevisyar.mehrdad32.ir/

The web tool converts Windows-1256 and other common subtitle encodings to UTF-8 locally, supports batch downloads, and shares TarikhDaar's dark/emerald design. Files are never uploaded.

## Original desktop application

The original Windows WPF project remains in [ZirnevisYar/](ZirnevisYar/) and [ZirnevisYar.sln](ZirnevisYar.sln). It targets .NET Framework 4.0.

Desktop source code has not been changed. The web version intentionally avoids deleting or replacing user files.
